# MYMS 앱 전체 디자인

기존 대화의 전체 디자인 개선과 이어서 마무리하라는 요청을 기준으로 작성한다.

## 방향

기존 SwiftUI 앱에 짙은 초록·라임 포인트, 옅은 바탕, 둥근 카드, 일관된 주요 버튼을 적용한다. 대규모 탐색 구조 교체보다 기존 다섯 화면의 역할을 정돈하는 방식을 유지한다. 새 웹 화면이나 별도 UI 런타임은 도입하지 않는다.

## 화면

- 로그인·회원가입: 워드마크와 소개, 명확한 필드, 로컬 시작 경로.
- 운동 계획: 요약, 계획별 운동 준비·운동 방법·편집·삭제, 빈 상태 안내.
- 운동: 큰 카메라와 진행 수치, 선택·시작·일시정지·종료·결과 동선. 세로와 큰 글자는 단일 열, 충분히 넓은 가로는 두 열.
- 기록: 주간 통계와 기록 목록, 시연·IMU 기록의 통계 제외 표시, 상세와 메모.
- 센서: 연결·측정 모드·시연을 앞에 두고 보정·환경·제스처 설정을 접어서 표시.
- 설정: 계정 요약·연령대·로그아웃·탈퇴 구분.

## 제약과 검증

기존 전신·손 추적, 기록·복구·포인트 규칙을 유지한다. 운영 DB와 펌웨어를 변경하지 않는다. iOS 17 대체 탭과 iOS 18 이상 적응형 사이드바를 유지한다. 다크 모드 색상은 공통 MYMSStyle에서 정의한다. 주요 채움 버튼은 밝은 배경에서 흰 글자, 다크 모드의 밝은 초록 배경에서 짙은 글자를 사용한다. 보조 테두리 버튼은 별도의 강조색을 유지한다. 검증은 실제 iPad XCTest, 별도 시뮬레이터 UI 테스트 및 캡처, 일반 앱 서명·설치·실행으로 나누어 기록한다. 실시간 카메라 정확도와 실제 센서 실측은 별도다.
