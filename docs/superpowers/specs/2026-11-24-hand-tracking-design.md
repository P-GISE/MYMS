# 전신 추적에 양손 추적 추가

사용자 요청: 기존 Thunder 전신 추적에 손을 펴고 쥐는 상태와 손가락 점을 추가한다. 같은 프레임에 전신 17개 점과 양손 각 21개 점을 그린다.

MediaPipe Gesture Recognizer는 Hand Landmarker와 손바닥/주먹 분류기를 함께 제공하므로 이 모델을 사용한다. 대안인 Hand Landmarker + 수동 각도 판정은 이번 요구에서 불필요한 휴리스틱을 늘린다. MediaPipe는 손, Thunder는 전신을 담당한다.

직렬 카메라 큐에서 한 프레임을 처리하고, 손 점과 손바닥·주먹·판별 중 상태를 표시한다. 분류 점수 0.6 미만, 다른 제스처, 잘린/잘못된 좌표는 주먹/펴짐으로 확정하지 않는다. 손이 사라지면 표시를 즉시 지운다. 자동 운동 조작이나 포인트 집계는 추가하지 않는다. 영상 저장/전송은 하지 않는다.

기존 UI와 센서 설정 분리를 유지한다. 동시 추론과 모델 리소스 로딩을 실제 iPad XCTest에서 검사하고, 최종 앱을 설치한다. 실시간 사용자 정확도는 기준 사진 검사와 구분한다.
