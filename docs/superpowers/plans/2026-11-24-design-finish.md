# MYMS 전체 디자인 마무리

**Goal:** 중단된 초록·라임 디자인을 보존하고 전체 화면과 운동 흐름을 검증한다.
**Architecture:** 기존 SwiftUI 카드·적응형 탐색·로컬 저장 구조를 유지한다.
**Scope:** 사용자의 기존 작업 계속 지시에 따라 현재 checkout에서 직접 진행한다. 커밋/푸시·서버 변경은 제외한다.

- [x] 운동 화면의 세로 iPad 배치를 단일 열로 수정한다. 가로 화면과 접근성 큰 글자 배치도 확인한다.
- [x] 로그인·계획·운동·기록·센서·설정의 기존 UI 자동 검사와 캡처를 다시 확인한다. 다크 모드·큰 글자 캡처를 추가한다.
- [x] 실제 iPad 19개 회귀 검사와 앱 빌드·서명·설치·실행을 확인한다.
- [x] 인수인계에 디자인 범위와 실제 검증 결과, 남은 실측 항목을 기록한다.

검증: 실제 iPad 19/19, 별도 UI 여정 1/1 통과. 일반 앱 clean build, 엄격한 코드 서명·리소스 검증, 설치·실행 확인. 리뷰에서 지적된 보조 버튼 전경색 상속을 수정했다. VoiceOver 실제 조작·실시간 카메라·ToF 실측·Swift Playground는 별도다.
