# MoveNet Thunder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** iPad 카메라에서 MoveNet Thunder 전신 17개 점과 연결선을 표시한다.

**Architecture:** TensorFlowLite Swift Interpreter를 직렬 카메라 큐에서 실행한다. 순수 좌표 디코더와 iOS 이미지 전처리/추론을 분리하고 기존 미리보기에 같은 프레임의 추론을 그린다.

**Tech Stack:** SwiftUI, AVFoundation, CoreGraphics, TensorFlowLite, MoveNet Thunder float16.

**Spec:** `docs/superpowers/specs/2026-11-24-movenet-design.md`

## Global Constraints

- iOS 17 이상, Xcode/Swift Playground 동일 소스.
- 영상 저장·전송 없음, 서버 변경 없음, 자동 횟수 집계 없음.
- 현재 checkout의 기존 UI 변경을 보존한다. 사용자 요청에 따라 구현·설치를 계속하며 별도 승인 절차나 새 worktree는 만들지 않는다.
