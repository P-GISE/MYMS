# MYMS 내장 센서 BLE 규격

현재 연결된 보드는 내부 I2C 주소 `10, 39, 44, 5C, 68`이 확인된 Nano 33 BLE Sense Rev2 센서 구성입니다.
펌웨어는 Arduino_BMI270_BMM150, Arduino_APDS9960, ArduinoBLE, VL53L0X 라이브러리를 사용합니다.
Rev1은 센서와 라이브러리가 다르므로 이 펌웨어를 그대로 사용하기 전에 별도 대응이 필요합니다.

서비스 UUID는 `19B10000-E8F2-537E-4F6C-D104768A1214`, 광고 이름은 `MYMS`입니다.
아래 특성은 동일한 UUID 뒷부분을 사용합니다. 정수와 IEEE 754 float32는 리틀 엔디언입니다.

| UUID 첫 묶음 | 값 | 속성 | 주기 |
|---|---|---|---|
| 19B10001 | 가속도 크기 `sqrt(x²+y²+z²)`, float32, g | Read, Notify | 약 100ms |
| 19B10002 | 근접 가상 버튼, uint8: 0 멀리, 1 가까이, 255 미측정 | Read, Notify | 측정 가능 시 약 100ms |
| 19B10003 | 내장 LED, uint8: 0 끔, 1 켬 | Read, Write | 쓰기 시 |
| 19B10004 | ToF 거리, uint16, mm; 0은 측정 불가 | Read, Notify | 약 100ms |
| 19B10005 | `[방향, 순환 일련번호]`, uint8 2개; 1 위, 2 아래, 3 왼쪽, 4 오른쪽 | Notify | 제스처 발생 시 |
| 19B10009 | APDS9960 clear 채널 원시 밝기, float32, 0~65535 counts | Read, Notify | 약 1초 |
| 19B1000A | 가속도 `[x, y, z]`, 각 float32 g, 총 12바이트 | Read, Notify | 약 100ms |

기존 온도06·습도07·기압08 특성은 제거했으며 새 의미로 재사용하지 않습니다. 이전 펌웨어와 연결한 앱은 새 특성이 없으면 밝기·경사를 미측정으로 처리해야 합니다.
float 센서 초기화 실패·유효하지 않은 측정은 NaN입니다. IMU는 마지막 정상 읽기 후 500ms, 밝기는 1500ms가 지나면 NaN으로 갱신합니다. 앱도 바이트 길이, 유한값, 갱신 시각을 확인해야 합니다. 표시된 주기는 하드 실시간 보장이 아닙니다.
LED에 0/1 외의 값을 쓰면 기존 상태를 유지하고 Read 값도 기존 상태로 복원합니다.
근접 기준은 APDS9960 라이브러리 값 기준 `<50`에서 누름, `>80`에서 해제이며 실제 케이스에서 보정해야 합니다.

밝기는 lux가 아닌 clear 채널 원시값입니다. `colorAvailable()`과 `readColor(r,g,b,clear)`를 사용하며 근접·제스처와 함께 폴링합니다. 실제 조명·케이스·센서 방향에 따라 달라지므로 밝고 어둠의 표시는 참고용입니다.

경사는 앱에서 사용자가 알려진 평평한 면에 보드를 놓고 기준을 저장한 뒤, 같은 보드 방향으로 측정 대상 면에 놓아 중력 벡터 사이의 각도로 계산합니다. 보드는 면에 밀착한 채 정지해야 합니다. 움직임·잘못된 기준·손목 장착 상태의 기울기는 바닥 경사가 아니며 운동 가능 여부를 확정하지 않습니다. 기준 또는 유효한 벡터가 없으면 0도로 추정하지 않고 미측정으로 표시합니다.
운동기구·장소·신발은 앱에서 직접 선택하여 운동 기록에 저장하며 BLE 센서 값으로 추측하지 않습니다.

거리 센서가 없어도 광고·연결·IMU·제스처·밝기 수신은 동작합니다. 고정된 보드의 IMU 값은 사용자의 비접촉 운동 횟수를 뜻하지 않습니다.
센서를 추가했다면 전원을 분리해 배선한 뒤 보드를 다시 시작해야 합니다.

고유 ID 특성 `19B1000B-E8F2-537E-4F6C-D104768A1214`는 Read 전용 ASCII 16바이트입니다. nRF52840 FICR DEVICEID[1], DEVICEID[0]을 각 8자리 대문자 16진수로 이어 붙입니다. 광고의 스캔 응답 이름과 GATT 기기 이름은 `MYMS`로 표시하며, 고유 ID는 이름에 붙이지 않습니다. iOS는 보드 ID를 직접 읽은 뒤 센서 알림을 구독합니다. 이전 펌웨어의 `MYMS-<16자리 ID>` 광고가 수신됐다면 추가 대조합니다. 보드 ID 누락·형식 오류·광고와 불일치는 연결 실패로 안내합니다. ID는 보드 식별용이며 암호학적 인증 수단은 아닙니다.
