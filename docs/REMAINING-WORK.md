- 앱 전체 디자인과 운동 화면의 카메라 배치 개선
- 전면 카메라 사용 및 사용 가능한 전면 초광각 카메라 우선 선택
- 카메라의 부위별 자세 키워드와 일반 감지 안내 문구 제거
- 실제 운동·시연 전환에 따른 주간 유효 횟수 그래프 및 최근 운동 기록 필터
- 시연 운동의 로컬 기록 저장과 실제 운동 통계 분리
- Arduino BLE 표시 이름을 `MYMS`로 변경하고 센서 UI에서 ID 숨김

### 1. 거리 센서 연결 및 실측

- [ ] VL53L0X 센서 도착 후 전원을 끄고 Arduino에 연결

- [ ] 운동별 센서 배치를 결정하고 횟수·유효 횟수의 정확성 검증

### 2. iPad 사용성 최종 확인

- [ ] 카메라 자세 보조를 켠 상태에서 운동 기록과 시작·정지 버튼이 스크롤 없이 보이는지 확인
- [ ] 전면 카메라의 전신·손 추적을 실제 동작으로 확인
- [ ] 화면 회전 시 레이아웃과 카메라 표시 확인
- [ ] BLE 연결 해제 후 재연결 확인

- [ ] 실제 운동·시연 탭에 따라 주간 그래프와 최근 기록이 함께 바뀌는지 확인

### 4. 서버 연동 마무리

- [ ] 담당자와 운영 DB 마이그레이션 적용 상태 확인
