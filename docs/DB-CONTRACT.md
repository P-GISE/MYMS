# DB와 센서 데이터 연결 범위

사용자가 제공한 컬럼·RLS와 현재 앱 소스를 비교한 결과입니다. 실제 DB 조회·쓰기·정책 변경은 수행하지 않았습니다.

아두이노는 BLE 측정 도구입니다. 거리·가속도·밝기·제스처·보드 ID를 iOS에 보내고, iOS가 운동 횟수·세트·시간을 계산해 DB 형식으로 변환합니다. 아두이노에는 Supabase URL·토큰·테이블 코드가 필요하지 않습니다.

| 정보 | 현재 저장 위치/동작 |
|---|---|
| profiles | id, age_group 읽기·쓰기 |
| workout_plans | 운동 설정·정렬 순서 전송 |
| workout_sessions | 고정 세션 UUID, 운동 설정, 실제 횟수·세트·시간·종료 시각·메모·포인트 전송 |
| feedback | nullable, 현재 앱 사용 안 함 |
| exercises / exercise_levels / recommendation_rules | 앱은 현재 서버 조회 대신 Swift에 정의된 설명·임계값·추천 사용 |
| 밝기·경사·운동기구·장소·신발·측정 모드 | 현재 DB 컬럼 없음, 계정별 기기 로컬 기록에 저장 |
| 진행 중 운동·중복 완료 장부 | 로컬 저장, 다른 iPad에서 복구되지 않음 |
| 보드 고유 ID | 연결 시 읽기·확인, 현재 운동 기록/DB 저장 안 함 |
| IMU 동작 테스트 기록 | 로컬만 저장, 서버 전송·포인트 제외 |

계획과 완료 기록 INSERT는 user_id를 생략합니다. 저장소 SQL에는 DEFAULT auth.uid()가 있으므로 같은 기본값이 실제 DB에도 있어야 합니다. 제공된 컬럼 표에는 DEFAULT가 없어 실제 설정은 확인되지 않았습니다. RLS만으로 값이 자동 입력되지는 않습니다.

동일 완료 UUID와 resolution=ignore-duplicates는 같은 완료 기록의 중복 행 생성을 막습니다. 로컬 완료 ID 장부는 중복 포인트를 막습니다. 제공된 RLS는 소유권 검사이며 서버에서 운동 수행/포인트의 진위를 검증한다는 의미는 아닙니다.
